# SnapWork · 사출입문 학습장

사진을 한 장씩 보며 사출성형 기초를 익히는 모바일 중심 학습 노트입니다. 이미지 위에 필기하고 텍스트 메모를 남길 수 있으며, 학습에 방해되지 않도록 기본 보기와 집중 편집 보기를 분리했습니다.

## 공개 페이지

- 사이트: <https://snapwork.kimkkkkm.chatgpt.site/>
- GitHub: <https://github.com/tlwh1/SnapWork>
- 현재 배포 기준 커밋: `d39b38918d9fc32424514bc44be15a56bd306101`

## 학습 내용

총 7페이지의 사출 입문 인포그래픽을 제공합니다.

1. 사출 한 사이클
2. 금형 구조
3. 사출기의 구조
4. 사출 조건
5. 자주 쓰는 수지 특성
6. 대표 불량
7. 유동 추적

## 사용 방법

1. 첫 화면에서 `학습 시작하기` 또는 원하는 페이지를 선택합니다.
2. 기본 보기에서는 이미지를 읽고 페이지 선택기, 이전·다음 버튼으로 이동합니다.
3. 이미지를 탭하거나 클릭하면 집중 편집 보기로 들어갑니다.
4. 집중 보기에서는 한 손가락(마우스 드래그)으로 필기하고, 두 손가락으로 확대·이동합니다.
5. `집중 보기 종료` 버튼, `Esc`, 또는 브라우저 뒤로가기로 기본 보기로 돌아갑니다. 뒤로가기를 한 번 더 누르면 목차로 돌아갑니다.
6. 텍스트 메모와 이미지 필기를 마친 뒤 `필기·메모 저장`을 눌러야 저장됩니다.

기본 보기에서는 이미지 편집 도구를 숨겨 실수로 선이 그어지지 않게 했습니다. 펜 투명도 기본값은 85%이며, 색상 5종과 굵기·투명도 조절을 지원합니다. 집중 보기의 색상 버튼은 색상 원이 포함된 팔레트를 열고, 선택 색은 슬라이더 강조색과 미리보기에도 반영됩니다. 굵기 점과 투명도 막대는 조절값을 실시간으로 보여 줍니다. 확대는 100~400% 범위에서 조절하고 초기화할 수 있습니다.

이전·다음 버튼은 각 페이지 제목 헤더 옆(모바일에서는 제목 바로 아래)에 배치되어 이미지까지 스크롤하지 않고도 넘길 수 있습니다.

모바일 상단은 돌아가기와 진행률을 한 줄로 압축하고, 페이지 선택기도 한 줄 높이로 줄여 학습 이미지가 더 빨리 보이도록 구성했습니다.

## 저장 방식

데이터는 서버로 전송하지 않고 현재 브라우저의 `localStorage`에만 저장됩니다.

- 키: `snapwork-study-0` ~ `snapwork-study-6` (페이지 번호는 0부터 시작)
- 값 형식: `{ "strokes": [...], "memo": "..." }`
- 필기 좌표는 이미지 대비 0~1 비율로 저장되므로 화면 크기가 달라도 다시 맞춰 그려집니다.
- 저장 버튼을 누르지 않은 변경사항은 페이지 이동·새로고침 시 버려집니다.
- 이전 버전 키인 `snapwork-redpen-*`도 읽을 수 있도록 호환 처리가 남아 있습니다.

## 저장소 구조

```text
SnapWork/
├─ dist/
│  ├─ index.html             # HTML·CSS·JavaScript가 포함된 정적 앱
│  ├─ images/                # 7개 원본 PNG와 웹 최적화 WebP
│  └─ .openai/hosting.json   # Sites 프로젝트 설정 사본
├─ docs/SESSION_HANDOFF.md   # 세션 종료용 인수인계 문서
└─ README.md
```

WebP를 우선 로드하고 PNG를 예비 경로로 사용합니다. 첫 로드 후 7개 WebP를 미리 읽어 페이지 전환 지연을 줄입니다.

## 로컬 실행

정적 파일이므로 별도 빌드 과정이 없습니다. 브라우저의 로컬 파일 보안 영향을 피하려면 간단한 HTTP 서버로 실행합니다.

```bash
python -m http.server 8787 --directory dist
```

그 다음 <http://127.0.0.1:8787/>을 엽니다. Node.js가 있다면 `npx serve dist`로도 확인할 수 있습니다.

## 배포 메모

- 기본 브랜치: `main`
- GitHub 원격: `origin`
- Sites 원격: `sites`
- Sites 프로젝트 설정은 `.openai/hosting.json`의 `project_id`를 사용합니다.
- 배포 전에는 `dist/`를 기준으로 패키징하고, 실제 소스 커밋 SHA와 일치하는지 확인해야 합니다.
- Sites 저장소 인증 토큰은 단기 자격증명으로만 사용하며 문서나 커밋에 기록하지 않습니다.

## 확인 체크리스트

- 모바일 폭에서 가로 스크롤이 생기지 않는가
- 기본 보기에서 필기 도구가 숨겨져 있고 이미지 탭으로 집중 보기에 들어가는가
- 집중 보기의 한 손가락 필기와 두 손가락 확대·이동이 충돌하지 않는가
- 저장 전 필기·메모가 `localStorage`에 기록되지 않는가
- 저장 후 새로고침해 필기와 메모가 복원되는가
- 집중 보기 종료 버튼과 브라우저 뒤로가기가 각각 올바른 단계로 이동하는가
- 7개 WebP 요청이 선로드되고 콘솔 오류가 없는가
