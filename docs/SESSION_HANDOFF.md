# SnapWork 세션 인수인계

작성일: 2026-09-16  
상태: 기능 구현 및 공개 배포 완료

## 현재 배포 상태

- 공개 URL: <https://snapwork.kimkkkkm.chatgpt.site/>
- GitHub: <https://github.com/tlwh1/SnapWork>
- 브랜치: `main`
- 마지막 커밋: 문제풀이 서버 동기화 변경 후 갱신
- 마지막 Sites 저장 버전: 서버 동기화 배포 버전
- `.openai/hosting.json`의 `project_id`를 그대로 사용해야 합니다.

## 이번 세션에서 확정한 UX

- 기본 보기는 학습·탐색 전용입니다. 이미지 위에 선을 그릴 수 없습니다.
- 이미지를 탭/클릭하면 집중 편집 보기로 진입합니다.
- 집중 보기에서 한 손가락은 필기, 두 손가락은 확대·이동으로 처리합니다.
- 집중 보기에는 별도 종료 버튼과 확대/축소·초기화 컨트롤이 있습니다.
- 색상은 색상 원 팔레트로 선택하며 선택 색이 슬라이더·굵기 점·투명도 미리보기에 동기화됩니다.
- 굵기와 투명도 값은 조절 중 미리보기와 숫자로 즉시 확인할 수 있습니다.
- 이전·다음 페이지 버튼은 이미지 아래가 아니라 페이지 제목 헤더 옆(모바일은 제목 아래)에 있습니다.
- 모바일 상단은 돌아가기·진행률을 한 줄에 배치하고 페이지 선택기 높이를 축소했습니다.
- 첫 화면의 `10문제 문제풀이`에서 100문제 문제은행을 주·객관식 카드로 풀 수 있습니다.
- 객관식은 선택 즉시 채점하고, 주관식은 핵심 단어 기준으로 자동 평가합니다.
- 문제 선정은 7개 주제 균형을 유지하면서 미출제·복습 시점·최근 오답에 가중치를 주는 간격 반복 방식입니다.
- 브라우저 뒤로가기는 `집중 보기 → 기본 보기 → 목차` 순서로 동작합니다.
- 이미지 필기와 텍스트 메모 모두 수동 저장 버튼을 눌렀을 때만 저장됩니다.

## 구현 메모

- 앱 화면은 `dist/index.html`에 HTML, CSS, JavaScript를 포함하고, `scripts/build-worker.cjs`가 WebP를 번들한 `dist/server/index.js` Cloudflare Worker를 생성합니다.
- Worker의 `/api/quiz/state`가 D1 `quiz_state` 테이블에 진행 상태를 GET/POST합니다. D1 논리 바인딩은 `.openai/hosting.json`의 `DB`입니다.
- 이미지 파일은 `dist/images/`에 PNG 원본과 WebP 최적화본이 함께 있습니다.
- 초기 로드 후 7개 WebP를 선로드합니다.
- 필기 좌표는 이미지 대비 비율로 저장하며, 캔버스 DPR은 최대 2로 제한합니다.
- 확대 상태는 페이지 이동 시 100%로 초기화됩니다.
- 페이지별 저장 키는 `snapwork-study-0`부터 `snapwork-study-6`입니다.
- 문제풀이 기록은 로그인한 사용자의 서버 D1 `quiz_state`에 저장합니다. 문제별 시도·정답·오답·연속 정답·복습 시각과 진행 중 세션(문제 순서·현재 위치·응답)을 함께 보관합니다.
- `oai-authenticated-user-id`를 서버 키로 사용하므로 같은 ChatGPT 계정으로 PC·모바일에서 이어풀 수 있습니다.
- 로그인하지 않은 공개 방문자는 퀴즈 화면에서 `로그인하고 기기 간 동기화`를 선택해야 하며, 정적 로컬 미리보기에서는 기존 `localStorage` 임시 모드를 사용합니다.

## 검증 결과

최종 수정 후 로컬 HTTP 서버와 공개 URL에서 다음을 확인했습니다.

- 모바일 390×844: 다크 테마, 7개 페이지, 가로 넘침 없음
- 데스크톱 1280px: 이미지와 캔버스 정렬, 가로 넘침 없음
- 기본 보기 이미지 탭 → 집중 보기 진입 및 해시 변경
- 한 손가락 필기는 저장 전 로컬 저장소에 기록되지 않음
- 두 손가락 포인터 입력은 선을 만들지 않고 확대 동작
- 저장 후 새로고침 시 필기·메모 복원
- 집중 보기 종료 및 브라우저 뒤로가기 단계 확인
- 10문제 세션 진행·즉시 피드백·세션 결과 및 오답 목록 확인
- 문제풀이 진행 데이터 저장과 다음 세션 오답 우선 출제 확인
- Worker API의 비로그인 401·인증 사용자 GET/POST·D1 업서트와 진행 세션 복원 확인
- 콘솔 오류 없음

## 다음 작업 시 주의

1. `dist/index.html`만 수정해도 되지만, 이미지 추가·교체 시 PNG와 WebP 경로 및 `pages` 배열을 함께 확인합니다.
2. 저장 포맷을 바꿀 경우 기존 `snapwork-study-*`와 `snapwork-redpen-*` 호환 여부를 먼저 검토합니다.
3. 배포할 때는 변경된 커밋을 GitHub `main`과 Sites 원격에 모두 push한 뒤, 그 정확한 SHA로 Sites 버전을 저장·배포합니다.
4. Sites 인증 토큰은 단기 자격증명으로 발급받아 명령 실행에만 사용하고 파일·README·커밋에 남기지 않습니다.
5. 배포 후에는 공개 URL에서 기본 보기 탭 진입, 필기, 두 손가락 제스처, 저장/복원을 최소 한 번 재확인합니다.

## 알려진 범위

- 이미지 필기·텍스트 메모는 브라우저별 저장이며, 문제풀이 기록만 서버 계정 동기화를 제공합니다.
- 서버 장애나 일시적인 네트워크 단절 때는 진행 중 퀴즈를 로컬 임시 보관하고 연결이 회복되면 다시 전송합니다.
- 오프라인에서 새 답을 계속 풀 수는 있지만 서버 동기화가 완료되기 전까지 다른 기기에는 반영되지 않습니다.
- 단계별 학습 콘텐츠 확장 계획은 `docs/LEARNING_ROADMAP.md`에 있습니다. 다음 추가 대상은 장비·안전·조건 화면 모듈입니다.
- 로드맵에는 Q-Net에서 확인한 컴퓨터응용선반기능사(1998-07-20)·정보처리산업기사(2004-08-16), 2027년 9월 전후 사출금형기사 응시 계획, 경력증명서 관리 원칙이 반영되어 있습니다.
- 매우 오래된 브라우저는 Pointer Events가 없어 보조 터치 이벤트 경로를 사용하므로, 새 기능은 최신 Chrome·Edge 기준으로 확인합니다.
