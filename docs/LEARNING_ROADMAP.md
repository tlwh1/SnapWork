# SnapWork 학습 로드맵

## 1. 학습자 프로필

- 플라스틱 사출기 관련 업체 입사 3일차의 완전 신입
- 당장의 목표는 기계 조작을 따라 하는 데서 멈추지 않고, 사출조건과 제품 변화를 설명할 수 있는 것
- 장기 목표는 사출 공정기술·생산기술·금형기술로 성장하고 사출금형기사에 응시·합격하는 것
- 과거 정보처리산업기사 취득 여부는 Q-Net에서 먼저 확인한다.

응시자격(산업기사 보유 여부, 관련 실무경력 인정 여부)은 반드시 Q-Net/한국산업인력공단의 공식 심사로 확인한다. 이 문서는 학습 계획이지 응시자격을 확정하는 문서가 아니다.

## 2. 최종 역량

다음 흐름을 스스로 설명하고 현장에서 확인할 수 있는 기술자를 목표로 한다.

`사출조건 → 불량 발생 → 가능한 원인 → 우선 확인 → 조건 변경 → 결과 확인`

최종적으로 확보할 역량은 다음 세 가지다.

1. 사출조건을 읽고 조정하는 능력
2. 금형·기계도면·CAD 구조를 이해하는 능력
3. 사출금형기사 수준의 이론과 실무 연결 능력

## 3. 단계별 계획

| 단계 | 시기 | 현장 학습 목표 | SnapWork에 추가할 학습 |
|---|---|---|---|
| 0. 공통 기초 | 현재 | 사출 사이클, 금형·조건·수지·불량·유동의 큰 그림 | 기존 7페이지 + 100문제 유지 |
| 1. 장비 적응 | 입사 0~1개월 | 회사 사출기 화면, 안전, 작동 순서, 조건 이름과 역할 | 사출기 조작 화면·안전·사이클 페이지 3~4장, 25~35문제 |
| 2. 불량·원료 진단 | 1~3개월 | 대표 불량을 여러 원인으로 나누고 확인 순서를 세우기 | 불량 사례·수지 비교 페이지 4~5장, 35~45문제 |
| 3. 금형·셋업 | 3~6개월 | 금형 부품, 금형 교환, 게이트·러너·냉각·벤트 구분 | 금형 구조·셋업 페이지 4~5장, 35~45문제 |
| 4. 도면·CAD | 6~9개월 | 투상·단면·공차·끼워맞춤과 SolidWorks 기초 | 도면 읽기·CAD 페이지 3~4장, 25~35문제 |
| 5. 기사·공정개선 | 9~12개월 이후 | 출제기준, 기출, 실기와 현장 트러블슈팅 연결 | 기사 핵심 요약·사례형 문제를 필요 시 추가 |

처음부터 모든 내용을 홈페이지에 넣지 않고, 각 단계에서 실제로 배운 내용과 회사 장비·수지에 맞춰 다음 모듈을 추가한다. 현재는 0단계만 운영하고 1단계부터 순서대로 확장한다.

## 4. 1단계부터 공부할 항목

### 장비·안전

- 형폐 → 형체 → 사출 → 보압 → 냉각 → 계량 → 형개 → 취출의 반복
- 사출 유닛과 형체 유닛의 역할
- 비상정지, 안전문, 저속 확인, 금형 주변 위험요소
- 회사에서 사용하는 화면의 명칭과 실제 위치

### 조건 화면

- 사출속도·사출압력·보압·보압시간
- V/P 전환위치·계량위치·쿠션량·배압·스크류 RPM
- 실린더·노즐·금형 온도, 냉각시간, 형체력, 사이클타임

각 항목은 숫자 암기보다 “이 값을 바꾸면 제품의 무엇이 왜 달라지는가?”를 설명하는 방식으로 학습한다.

## 5. 2단계 이후의 핵심 원칙

### 불량

미성형, 바리, 싱크마크, 웰드라인, 번마크, 실버스트릭, 플로우마크, 휨, 보이드, 흑점, 제팅, 게이트 자국을 구분한다.

`불량 하나 = 조건 하나`로 단정하지 않고 다음 순서로 접근한다.

1. 어떤 불량인가?
2. 사출조건·금형·수지·설비 중 어디를 먼저 의심할까?
3. 현장에서 무엇을 확인할까?
4. 어떤 조건을 왜 바꿨을까?
5. 제품과 기록이 어떻게 변했을까?

### 수지

회사에서 실제 쓰는 수지를 먼저 기록하고 PP, PE, ABS, PC, PC/ABS, PA, POM, PMMA, TPE 순서로 확장한다. 건조 필요 여부·건조조건·성형온도·금형온도·수축·흡습성·결정성·유동성·강도·내열성을 불량과 연결한다.

### 금형·도면

고정측·가동측·캐비티·코어·스프루·러너·게이트·이젝터·가이드·파팅라인·냉각수로·벤트·슬라이드·핫러너를 실제 금형과 연결한다. 이후 투상도·단면도·공차·끼워맞춤·표면거칠기·기하공차와 SolidWorks의 Sketch·Extrude·Cut·Revolve·Pattern·Fillet·Assembly·Drawing을 금형도면 읽기에 필요한 만큼 익힌다.

## 6. 개인 사출 데이터베이스

입사 초기부터 다음 형식으로 기록한다.

| 날짜 | 제품·금형 | 원료 | 불량 | 변경 전 | 변경한 조건 | 변경 이유 | 결과 | 선배 설명 | 내 추정 |
|---|---|---|---|---|---|---|---|---|---|

단순히 `PP / 미성형 / 속도 45→50`으로 끝내지 않고, 왜 속도를 바꿨는지와 확인한 다른 원인을 함께 적는다. 이 기록이 향후 개인 조건표와 트러블슈팅 데이터베이스가 된다.

## 7. 홈페이지 확장 방식에 대한 판단

단계적으로 추가하는 방식이 더 적합하다.

- 입사 초기에는 회사 장비·화면·안전 절차가 일반 교재보다 중요하다.
- 현장에서 확인하지 않은 숫자나 조건을 일괄 추가하면 잘못된 암기가 생길 수 있다.
- 한 모듈을 학습한 뒤 바로 문제로 확인해야 무엇을 이해하지 못했는지 드러난다.
- 모듈별로 학습 페이지와 20~45문제를 함께 추가하면 기존 간격 반복 출제 로직이 자연스럽게 작동한다.
- 새 모듈은 “설명 가능 → 현장 확인 가능 → 사례 판단 가능”의 세 기준을 통과할 때 다음 단계로 넘어간다.

따라서 앞으로는 사용자가 현장에서 배운 내용·사진·조건·불량을 알려주면, 그 자료를 검토해 다음 순서로 확장한다.

1. 학습 페이지 초안 작성
2. 핵심 용어·현장 확인 목록 정리
3. 객관식·단답형·사례형 문제 추가
4. 기존 문제와 중복·난이도 점검
5. 실제 학습 후 피드백을 반영해 보완

이번 요청에서는 로드맵만 문서화했으며 홈페이지의 학습 내용은 기존 7페이지를 유지한다. 다음 단계에서 1단계 장비·안전 모듈부터 추가하는 것이 가장 효율적이다.

## 8. AI에게 요청할 답변 형식

앞으로 사출 관련 질문에는 다음 순서로 답한다.

1. 사출성형 원리
2. 가능한 원인(조건·금형·수지·설비로 나누기)
3. 현장에서 먼저 확인할 항목
4. 조건 변경 방향과 변경 이유
5. 결과 기록 방법과 주의점

설명은 신입이 이해할 수 있게 시작하되, 점차 조건 분석·공정 개선·사출금형기사 준비 수준으로 높인다.

## 9. 자격증·응시 계획 업데이트 (2026-09-16)

### 14. 확인된 국가기술자격

Q-Net 자격증취득조회에서 과거 취득 이력을 실제로 확인했다.

1. **컴퓨터응용선반기능사(검정형)** — 최종합격일: `1998-07-20`
2. **정보처리산업기사(검정형)** — 필기합격일: `2004-06-07`, 최종합격일: `2004-08-16`

따라서 정보처리산업기사 보유 사실은 기억이 아니라 Q-Net에 등록된 확인 사실로 기록한다. 다만 취득 시점이 오래되었으므로 당시 지식이 현재에도 유지된다고 가정하지 않고, 필요한 기계·도면 내용은 기초부터 다시 복습한다.

### 15. 사출금형기사 응시자격 계획

국가기술자격 기사 응시경로 중 다음 기준을 우선 검토한다.

> 산업기사 등급 이상의 자격을 취득한 후, 응시하려는 종목이 속하는 동일 및 유사 직무분야에서 1년 이상 실무에 종사한 사람

현재 계획은 다음과 같다.

`정보처리산업기사 취득(2004-08-16) → 사출 관련 업무 입사(2026-09) → 사출 실무 1년 확보(2027-09 전후) → Q-Net/한국산업인력공단 경력 인정 확인 → 사출금형기사 응시`

핵심 조건은 **사출금형기사의 동일·유사 직무분야로 인정되는 실무경력 1년**이다. 현재 회사에서 수행하는 업무가 실제로 해당 분야에 포함되는지는 업무 내용과 경력증명서를 바탕으로 한국산업인력공단의 최종 심사를 받아야 한다. 이 문서는 응시자격을 확정하는 문서가 아니다.

현 계획에서는 정보처리산업기사를 다시 취득하거나 사출금형산업기사를 반드시 먼저 취득하는 경로를 전제로 하지 않는다. 응시자격 심사 결과나 시험제도 변경이 있으면 계획을 갱신한다.

### 16. 경력증명서와 업무기록 관리

앞으로 1년은 재직기간만 채우는 시간이 아니라, 실제 사출 직무 경험을 증명할 수 있도록 기록하는 기간으로 운영한다.

실제로 수행한 업무라면 다음 항목이 회사 업무기록이나 경력증명서에 구체적으로 남도록 확인한다.

- 플라스틱 사출성형 업무
- 사출성형기 운전 및 관리
- 사출조건 설정·관리
- 금형 교환 및 셋업
- 사출공정 관리
- 성형불량 확인 및 개선
- 금형·사출설비 점검
- 사출제품 생산관리

`생산직`, `현장직`, `기계조작`처럼 넓은 표현만 남기기보다 담당한 사출 업무를 구체적으로 적는 편이 확인에 유리하다. 단, 경력증명서에는 반드시 실제 수행 업무만 기재하며 사실과 다른 업무를 추가하지 않는다.

### 17. 자격증 전략 변경

정보처리산업기사 보유 사실이 확인되었으므로 현재 우선순위는 다음과 같다.

`사출 실무 1년 확보 + 사출금형기사 직접 응시 준비`

사출금형산업기사를 중간 단계로 취득하는 방안은 필수 경로가 아니라 보조 선택지로 둔다. 실무경력 인정 여부, 시험 일정, 학습 진도에 따라 필요성이 생길 때만 다시 검토한다.

### 18. 앞으로 1년의 핵심 목표

1. **사출 실무경력 확보** — 기간뿐 아니라 사출성형 공정과 조건을 실제로 이해한다.
2. **사출금형기사 준비** — 필기와 실기를 함께 고려해 기계제도·금형구조·CAD를 미리 익힌다.
3. **현장 판단력 확보** — `불량 발생 → 현상 확인 → 원인 범주화(조건·금형·원료·설비) → 변경 → 결과 확인` 흐름을 스스로 수행한다.

### 19. 기사 준비 우선순위

| 시기 | 우선 학습 | 현장·학습 산출물 |
|---|---|---|
| 입사 0~3개월 | 사출기 구조, 사출 사이클, 사출조건, 원료, 대표 불량 | 장비 용어표와 불량 확인 순서 |
| 입사 3~6개월 | 금형구조, 금형교환, 게이트, 러너, 냉각, 벤트, 이젝터 | 금형 부품 스케치와 셋업 체크리스트 |
| 입사 6~9개월 | 기계제도, 도면해독, 공차, 끼워맞춤, CAD·SolidWorks 기초 | 도면 읽기 연습과 간단한 3D 모델 |
| 입사 9~12개월 | 사출금형기사 필기·기출, 금형설계 이론, 실기 CAD·도면 | 기출 오답노트와 실기 연습 기록 |
| 경력 1년 전후 | Q-Net 응시자격·경력증명서 확인, 한국산업인력공단 심사 | 응시 가능 여부 확인 후 시험 일정 확정 |

입사 초기에는 기사 기출 암기보다 실제 업무와 기본 원리 이해를 우선한다. 현장 경험이 쌓일수록 기출문제와 실기 연습의 비중을 높인다.

### 20. 현재 자격증 측면의 장점과 보완점

컴퓨터응용선반기능사와 정보처리산업기사 취득 경험이 있어 국가기술자격 시험의 학습·응시 절차를 이미 경험했다. 기계가공·기계 분야를 완전히 처음 접하는 사람과 비교하면 과거의 기초 경험을 활용할 수 있다.

반면 자격 취득 시점이 오래되었으므로 기계제도·가공·전산 관련 지식은 처음부터 현재 기준으로 복습한다. 기존 자격증은 사출 실무를 대신하지 않으며, 현재 업무와 응시자격의 연결은 별도로 확인한다.

### 21. 최종 커리어 방향

우선 다음 조합을 갖춘다.

`사출 현장경력 + 사출조건 셋업·트러블슈팅 + 금형구조 이해 + 기계도면/CAD + 사출금형기사`

이후 직무 필요성에 따라 다음 영역을 확장한다.

`유압·공압 → 전기·센서 → PLC → 자동화·로봇 → 품질·SPC → DOE·공정최적화 → 설비보전`

### 22. AI가 참고할 최신 상태

- 현재 시점은 2026년 9월이며, 플라스틱 사출 관련 업체 입사 3일차 수준의 신입이다.
- Q-Net에서 정보처리산업기사(최종합격 2004-08-16)와 컴퓨터응용선반기능사(최종합격 1998-07-20) 취득 사실을 확인했다.
- 앞으로 약 1년 동안 사출 실무와 사출금형기사 준비를 병행한다.
- 현재 최우선 자격증 목표는 사출금형산업기사가 아니라 사출금형기사 직접 응시다.
